MedLine Community Healthcare and Appointment Services - Resit Dataset

This synthetic dataset supports the Databases and Analytics resit case study. It contains structured CSV files for SQL in R, R analytics, and Python data processing, plus a MongoDB-ready JSONL file for NoSQL modelling.

Suggested tasks:
- Analyse appointment cancellation/no-show rates by clinic and service type.
- Compare waiting days and patient satisfaction.
- Identify referral and prescription delays.
- Examine nurse visit delay patterns.
- Import patient_service_cases.jsonl into MongoDB Atlas and create queries/aggregations.
- Apply indexes on case_id, patient_id, case_status, priority, opened_date, and events.event_type where appropriate.

All data is fictional and created for teaching and assessment purposes only.
